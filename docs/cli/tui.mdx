---
title: "Terminal UI"
description: "The layout, the status line and the keyboard controls."
---

Running `tnt` with no arguments opens the interactive session.

## Layout

```
+ transcript -------------------------------------------------+
| finished messages live in the terminal scrollback           |
| the message still being written is redrawn in place         |
+-------------------------------------------------------------+
| jump hint (only while scrolled back)                        |
| goal (when set)                                             |
| todo rows (up to five unfinished)                           |
| ┌─[mode]───────────────────────────────────────────────────┐ |
| │ > your input                                            │ |
| └─────────────────────────────────────────────────────────┘ |
| workspace | context | cache | model | thinking              |
+-------------------------------------------------------------+
```

Finished messages are printed once and scroll up like ordinary terminal output,
so the scrollback stays usable while the agent works. Only the live tail, the
streaming answer, the running tool call and a permission prompt, is redrawn.

## Status line

The line under the composer reports, from left to right:

| Item      | Meaning                                                   |
| --------- | --------------------------------------------------------- |
| workspace | current directory and git branch                          |
| context   | share of the context window already used                  |
| cache     | share of prompt tokens served from cache, to two decimals |
| model     | selected model                                            |
| thinking  | reasoning effort when the model exposes it                |

## Composer

The placeholder lists what the input understands: plain text, `@` to attach
context, `/` for commands, `!` to run a shell command directly.

The session goal and the todo list render above the box. Only unfinished todos
are listed, at most five; completed items appear in the `Todos done/total`
header, and further unfinished ones collapse into `· +N` there. The todo panel
disappears when nothing is left unfinished.

## Thinking

Reasoning streams into the transcript as it arrives and folds behind
`Thinking...` when the turn ends. Click a folded block to open it, or press
`Ctrl+O` to toggle every finished block. Open blocks stay open.

## Images

Press `Ctrl+V` in the composer to attach an image from the clipboard. The image
is inserted as an `[Image #N]` placeholder and sent with the next message;
images larger than 1024×1024 are scaled down first. The clipboard is read only
when you press the key; there is no clipboard marker or background polling.

On Linux the image is read with `wl-paste` on Wayland and `xclip` on X11 when
they are installed. Otherwise TNT falls back to a bundled X11 helper that also
works under XWayland; a pure Wayland session without XWayland needs
`wl-clipboard` installed. macOS reads the clipboard through `osascript` and
Windows through PowerShell, with the bundled helper as the fallback.

## Themes

`/theme` picks a built-in palette with a live preview: `auto` follows the
terminal's own light or dark background, and `dark`, `tencent-dark`,
`tencent-light` and `light` are fixed. The same choice can be set with
`TNT_THEME` or `theme:` in `config.yaml`.

A theme of your own is a JSON file in `~/.tnt/themes/<name>.json`, selected with
`TNT_THEME=<name>`:

```json title="~/.tnt/themes/night.json"
{
  "accent": "#ff79c6",
  "text": { "primary": "#f8f8f2" },
  "diff": { "addText": "#50fa7b" }
}
```

Only the tokens you name change; the rest come from the dark palette, so a file
that only wants a different accent is two lines. A key the palette does not have,
or a value that is not a string, is ignored and the token keeps its built-in
colour - a typo cannot blank a panel. A file that is not JSON is ignored the same
way, and a name with no file behind it falls back to `dark`.

## Command palette

`Ctrl+P` lists every command the session can run, with a filter that matches the
name or the description. Enter runs the highlighted one through the same path as
typing it, so a command that asks for an argument still asks for it; Esc closes
the palette without running anything.

## Keys

| Key                   | Action                                                |
| --------------------- | ----------------------------------------------------- |
| `Enter`               | send                                                  |
| `Shift+Enter`         | insert a newline instead of sending                   |
| `Shift+Tab`           | cycle the permission mode                             |
| `Ctrl+F`              | search the input history                              |
| `Ctrl+O`              | expand or fold reasoning rows                         |
| `Ctrl+B`              | send the running tool call to the background          |
| `Ctrl+X` / `Ctrl+R`   | take the newest queued message back (R also edits it) |
| `Esc`                 | interrupt the current turn                            |
| `Up` / `Down`         | move through earlier input                            |
| `Tab`                 | accept the highlighted completion                     |
| `Ctrl+V`              | attach an image from the clipboard                    |
| `PageUp` / `PageDown` | scroll the transcript one page                        |
| `Home` / `End`        | jump to the start / live tail                         |
| `Ctrl+End`            | jump to the live tail while the composer has focus    |
| mouse wheel           | scroll the transcript                                 |
| click the `↓` hint    | jump to the live tail                                 |
| `Ctrl+P`              | open the command palette                              |
| `Ctrl+L`              | clear the screen                                      |
| `Ctrl+C`              | clear the input, twice to exit                        |
| `Ctrl+D`              | exit                                                  |

<Tip>
  `/exit` and `Ctrl+C` twice leave the session. Sessions are saved as they run,
  so `tnt --resume` picks the same conversation back up.
</Tip>
