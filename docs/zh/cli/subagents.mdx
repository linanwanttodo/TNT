---
title: "子智能体"
description: "把任务委派给运行在同一引擎上的子智能体。"
---

子智能体在自己的会话中运行任务，同时父会话继续工作。它使用与父会话相同的引擎、
模型和权限模式。

<Info>
在委派接口稳定之前，Subagent 工具由 `--beta-subagent-tool` 参数控制。
</Info>

## 查看和返回

```
/subagents
```

列出从当前会话委派的会话。

```
/back
```

返回父会话。委派会话的记录以只读方式打开：可以查看子会话，但修改发生在拥有该
工作的会话中，因此两个智能体不能同时改写同一条对话。

## 缓存行为

子智能体继承父会话的 prompt 缓存键，因此共享前缀会从缓存读取，而不是重新付费。
嵌套委派被有意限制得较浅：允许子会话继续扩散会成倍增加缓存写入，复用带来的节省
就消失了。如果委派任务需要更多并行度，这通常意味着应该从父会话拆成两个委派任务。
