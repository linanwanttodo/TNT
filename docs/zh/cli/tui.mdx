title: "终端界面"

---

不带参数运行 `tnt` 会打开交互式会话。

## 布局

```
+ transcript -------------------------------------------------+
| 完成的消息留在终端回滚缓冲区里                              |
| 仍在写入的消息会原地重绘                                    |
+-------------------------------------------------------------+
| composer                                                    |
|   模式指示 | 目标（设置后显示）                             |
|   > 你的输入                                                |
|   工作区 | 上下文 | 缓存 | 模型 | 思考                      |
+-------------------------------------------------------------+
```

完成的消息只打印一次，并像普通终端输出一样向上滚动，因此智能体工作时回滚缓冲区
仍然可用。只有实时尾部、正在流式输出的回答、运行中的工具调用和权限提示会被
重绘。

## 状态栏

输入框下方一行从左到右显示：

| 项目 | 含义 |
| --- | --- |
| 工作区 | 当前目录和 git 分支 |
| 上下文 | 已使用的上下文窗口比例 |
| 缓存 | provider 报告的 prompt 缓存读取量 |
| 模型 | 当前选中的模型 |
| 思考 | 模型暴露的推理强度 |

## 输入框

占位提示会列出输入框支持的内容：普通文本、用 `@` 附加上下文、用 `/` 触发命令、
用 `!` 直接运行 shell 命令。

## 按键

| 按键 | 操作 |
| --- | --- |
| `Enter` | 发送 |
| `Shift+Enter` | 插入换行而不是发送 |
| `Shift+Tab` | 循环切换权限模式 |
| `Esc` | 中断当前回合 |
| `Up` / `Down` | 在之前的输入中移动 |
| `Tab` | 接受高亮的补全 |
| `Ctrl+C` | 清空输入，按两次退出 |

<Tip>
`/exit` 和连续两次 `Ctrl+C` 会离开会话。会话在运行过程中保存，因此
`tnt --resume` 可以接着同一个对话继续。
</Tip>
