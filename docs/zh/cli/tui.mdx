title: "终端界面"

不带参数运行 `tnt` 会打开交互式会话。

## 布局

```
+ transcript -------------------------------------------------+
| 完成的消息留在终端回滚缓冲区里                              |
| 仍在写入的消息会原地重绘                                    |
+-------------------------------------------------------------+
| 跳转提示（仅在向上滚动时显示）                              |
| 目标（设置后显示）                                          |
| 待办行（最多 5 条未完成）                                   |
| ┌─[模式]───────────────────────────────────────────────────┐ |
| │ > 你的输入                                              │ |
| └─────────────────────────────────────────────────────────┘ |
| 工作区 | 上下文 | 缓存 | 模型 | 思考                        |
+-------------------------------------------------------------+
```

完成的消息只打印一次，并像普通终端输出一样向上滚动，因此智能体工作时回滚缓冲区
仍然可用。只有实时尾部、正在流式输出的回答、运行中的工具调用和权限提示会被
重绘。

## 状态栏

输入框下方一行从左到右显示：

| 项目   | 含义                                        |
| ------ | ------------------------------------------- |
| 工作区 | 当前目录和 git 分支                         |
| 上下文 | 已使用的上下文窗口比例                      |
| 缓存   | prompt token 中命中缓存的比例，保留两位小数 |
| 模型   | 当前选中的模型                              |
| 思考   | 模型暴露的推理强度                          |

## 输入框

占位提示会列出输入框支持的内容：普通文本、用 `@` 附加上下文、用 `/` 触发命令、
用 `!` 直接运行 shell 命令。

会话目标和待办列表显示在输入框上方。只列未完成的待办，最多 5 条；已完成的数量
显示在 `待办 done/total` 标题里，多出来的未完成项收在同行的 `· +N` 中。没有未完成
项时待办面板整体隐藏。

## 思考

推理内容会随着流式输出显示在对话里，回合结束后折叠成 `思考中…` 一行。点击折叠块
可以展开，再点一次收起；`Ctrl+O` 切换所有已完成块的展开状态。展开过的块会保持展开。

## 图片

在输入框里按 `Ctrl+V` 可以把剪贴板中的图片附加到消息上。图片以 `[Image #N]`
占位符插入，随下一条消息一起发送；超过 1024×1024 的图片会先缩小。只有按下
`Ctrl+V` 时才会读取剪贴板，状态栏不显示标记，也不会在后台轮询。

Linux 下 Wayland 优先用 `wl-paste`，X11 用 `xclip`（需已安装）；都没有时回退到
内置的 X11 辅助模块，它在 XWayland 下也可用。没有 XWayland 的纯 Wayland 会话需要
安装 `wl-clipboard`。macOS 通过 `osascript`、Windows 通过 PowerShell 读取剪贴板，
失败时使用内置辅助模块。

## 主题

`/theme` 可以从内置配色里选一个并实时预览：`auto` 跟随终端自身的明暗背景，`dark`、
`tencent-dark`、`tencent-light`、`light` 是固定配色。也可以用 `TNT_THEME` 或
`config.yaml` 里的 `theme:` 指定同一个选择。

自己的主题是一个 JSON 文件，放在 `~/.tnt/themes/<名字>.json`，用 `TNT_THEME=<名字>`
选中：

```json title="~/.tnt/themes/night.json"
{
  "accent": "#ff79c6",
  "text": { "primary": "#f8f8f2" },
  "diff": { "addText": "#50fa7b" }
}
```

只有你写了名的 token 会变，其余继承深色配色，所以只想换强调色的文件只有两行。配色里
没有的键、或不是字符串的值会被忽略并保留内置颜色——写错一个键不会让面板变空白。不是
JSON 的文件同样被忽略；名字对应不到文件时回落到 `dark`。

## 命令面板

`Ctrl+P` 列出本会话能运行的全部命令，筛选同时匹配名字与描述。回车执行的路径与手动输入
完全相同，所以需要参数的命令仍然会要参数；Esc 关闭面板且不执行任何命令。

## 按键

| 按键                  | 操作                                     |
| --------------------- | ---------------------------------------- |
| `Enter`               | 发送                                     |
| `Shift+Enter`         | 插入换行而不是发送                       |
| `Shift+Tab`           | 循环切换权限模式                         |
| `Ctrl+F`              | 搜索输入历史                             |
| `Ctrl+O`              | 展开或折叠思考内容                       |
| `Ctrl+B`              | 把正在运行的工具调用转到后台             |
| `Ctrl+X` / `Ctrl+R`   | 取回最新一条排队消息（R 还会放回输入框） |
| `Esc`                 | 中断当前回合                             |
| `Up` / `Down`         | 在之前的输入中移动                       |
| `Tab`                 | 接受高亮的补全                           |
| `Ctrl+V`              | 附加剪贴板中的图片                       |
| `PageUp` / `PageDown` | 翻页滚动对话                             |
| `Home` / `End`        | 跳到开头 / 最新位置                      |
| `Ctrl+End`            | 输入框聚焦时跳到最新位置                 |
| 鼠标滚轮              | 滚动对话                                 |
| 点击 `↓` 提示         | 跳到最新消息                             |
| `Ctrl+P`              | 打开命令面板                             |
| `Ctrl+L`              | 清屏                                     |
| `Ctrl+C`              | 清空输入，按两次退出                     |
| `Ctrl+D`              | 退出                                     |

<Tip>
  `/exit` 和连续两次 `Ctrl+C` 会离开会话。会话在运行过程中保存，因此 `tnt
  --resume` 可以接着同一个对话继续。
</Tip>
