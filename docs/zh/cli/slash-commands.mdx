---
title: "斜杠命令"
description: "输入框中以斜杠开头的所有功能。"
---

在输入框中输入 `/` 可以过滤下面的列表。描述会跟随所选语言，见[语言](/zh/cli/i18n)。

## 会话

| 命令 | 作用 |
| --- | --- |
| `/help` | 显示帮助信息 |
| `/clear` | 清空对话历史 |
| `/info` | 显示会话信息 |
| `/exit` | 离开对话 |
| `/sessions` | 显示所有已保存的会话 |
| `/resume` | 恢复之前的会话 |
| `/fork` | 从当前历史开始一个新会话 |
| `/title` | 设置会话标题 |
| `/rename` | 重命名会话 |
| `/export` | 把会话导出为 JSON 文件 |
| `/import` | 从 JSON 文件导入会话 |
| `/goal` | 设置会话正在推进的目标 |
| `/todos` | 列出当前会话的待办项 |

## 模型和配置

| 命令 | 作用 |
| --- | --- |
| `/model` | 在已配置的模型之间切换 |
| `/think` | 设置或查看本次会话的推理深度（`off`、`low`、`medium`、`high`、`xhigh`、`max`、`default`） |
| `/init` | 创建 `AGENTS.md` 文件 |
| `/language` | 切换界面语言 |
| `/update` | 更新 TNT 安装 |
| `/theme` | 选择界面主题（实时预览） |
| `/profile` | 切换工作模式 |
| `/output-style` | 切换输出风格 |

## 能力

| 命令 | 作用 |
| --- | --- |
| `/mcp` | 管理 MCP 服务器连接 |
| `/plugins` | 列出已安装插件及其贡献 |
| `/skills` | 列出可用技能 |
| `/import-skill` | 把技能导入 `~/.tnt/skills` |
| `/subagents` | 显示从当前会话委派的会话 |
| `/back` | 从委派会话返回父会话 |
| `/parent` | `/back` 的别名 |
| `/jobs` | 列出后台任务 |
| `/cost` | 显示本会话的上下文、缓存、输出与费用 |

## 上下文和工作区

| 命令 | 作用 |
| --- | --- |
| `/compact` | 把历史总结成紧凑形式 |
| `/diff` | 显示来自远程环境的当前 diff |
| `/apply` | 把该 diff 应用到本地工作树 |
| `/index` | 查看或管理代码库索引 |
| `/diagnostics` | 显示语言服务器诊断 |

<Note>
打开选择器的命令（例如 `/model`、`/sessions` 和 `/mcp`）支持方向键和 Enter，
按 `Esc` 会返回输入框且不改变任何内容。
</Note>
