---
title: "语言"
description: "切换界面语言，并了解默认语言来自哪里。"
---

界面目前提供英文和简体中文。

```
/language
```

列出可用语言并标出当前语言，而

```
/language zh-CN
```

切换到该语言。切换立即生效并会保存，因此下次启动仍使用同一种语言。

## 默认值

尚未选择语言时，TNT 跟随环境：`zh_CN.UTF-8` 这样的 locale 选择简体中文，
其他情况选择英文。读取的变量依次为 `LC_ALL`、`LC_MESSAGES`、`LANG` 和
`LANGUAGE`。

## 哪些内容会被翻译

斜杠命令描述、选择器、通知和面向用户的界面文本会翻译。模型输出不会翻译，
代码、路径和工具输出按原样显示。

## 选择保存在哪里

`~/.tnt/settings.json` 中的 `locale` 字段保存选择。删除该字段后，界面会回到
根据环境推导的默认语言。
