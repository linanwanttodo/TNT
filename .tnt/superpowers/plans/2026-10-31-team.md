# /team 专家团 v1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把子代理与专家团合并为一个模型：并行 keyed 派发、团队名册（文件）、`/team` 命令、纪律规范文档。

**Architecture:** 先落规范文档（人格提示词的上位依据）；Subagent 工具从全局独占槽改为 keyed claim（`files` 参数）；新增 TeamService 扫描三层名册并接入派发查询链；默认团队两份 markdown 名册；`/team` 四形态命令。

**Tech Stack:** TypeScript (NodeNext), vitest, TNT services container, planner keyed-claim 机制.

**Spec:** `.tnt/superpowers/specs/2026-10-31-team-design.md`（实现者必须先读）

## Global Constraints

- 缓存前缀稳定性：/team 一切注入不改静态 spine；领队提示词走 userRules 分节（volatile: true），激活即 latch。
- `SubagentRestriction` 只有 `"readonly" | "no-writes"` 两种（runContext.ts:47），设计文档里的 `full` 指省略 restriction（继承会话），不新增枚举值。
- 相对导入带 `.js` 扩展名；commit 短祈使句无 AI 署名；测试从 `packages/cli` 运行。
- tsc 必须在 `packages/cli` 目录跑（仓库根会误报 core/ 的 esModuleInterop）。
- 团队文件名 `name` 全局唯一，优先级 用户项目 `.tnt/teams/` > 全局 `<continueHome>/teams/` > 默认（taken-set 语义，重名告警取先到者；默认最低）。
- 名册文件 frontmatter 字段：`name`（必填）、`description`（必填）、`restriction`（可选）、`deniedTools`（可选，逗号分隔）、`team`（必填）、`lead`（可选 boolean）。正文 = 系统提示词。
- 每个 commit 完成后立即在 `docs/worklogs/2026-10-31-optimization-log.md` 追加一节（做了什么/为什么/依据来源/验证方式）。
- superpowers 产物一律放 `.tnt/superpowers/`（`.tnt/AGENTS.md` 硬规则）。

## Review Focus

- 未声明 `files` 的 Subagent 调用必须回落全局独占槽（与改动前行为完全一致）——Task 1 的 `falls back to the exclusive slot when files is absent` 测试钉死。
- `files` 里的路径要有 pathKeys 同样的规范化（绝对/相对/`./` 前缀）；两个代理声明 `src/a.ts` 与 `./src/a.ts` 必须判重叠——Task 1 测试钉死。
- 名册目录不存在、文件坏 frontmatter、缺 name：告警不中断（与 plugin loader 一致）——Task 3 测试钉死。
- `/team <name>` 对不存在的团队：i18n 化的错误信息列出可用团队，不崩溃——Task 6 测试钉死。
- 激活态跨 compaction/会话恢复不要求保留（v1 内存态，设计已声明）；但同会话内 list 工具输出必须即时反映激活——Task 5 测试钉死。

```typescript
it("keys subagent calls by their declared files", () => {
  const claim = claimForToolCall("Subagent", {
    files: ["src/a.ts", "src/b.ts"],
  });
  expect(claim.exclusive).toBe(false);
  expect(claim.keys).toEqual(["src/a.ts", "src/b.ts"]);
});

it("overlapping subagent file scopes normalize to the same key", () => {
  const a = claimForToolCall("Subagent", { files: ["src/a.ts"] });
  const b = claimForToolCall("Subagent", { files: ["./src/a.ts"] });
  expect(a.keys).toEqual(b.keys);
});

it("falls back to the exclusive slot when files is absent", () => {
  expect(claimForToolCall("Subagent", {})).toEqual({
    exclusive: true,
    keys: [],
  });
  expect(claimForToolCall("Subagent", { files: [] })).toEqual({
    exclusive: true,
    keys: [],
  });
});
```
